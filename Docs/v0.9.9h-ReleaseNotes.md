# v0.9.9h Release Notes

Built on: v0.9.9g (field-run baseline). Fix release only, no new features. Scope approved 2026-11-16 from the v0.9.9g code review.

## Fixed

### 1. AD DS / DNS / DHCP collected from the target, with the supplied credentials (review H1)
- **Before:** these collectors ran as a local job on the operator PC and ignored the alternate credentials. AD DS called `Get-ADForest`/`Get-ADDomain`/`Get-ADDomainController` with no `-Server`, so a DC in another domain was documented with **the operator PC's forest, domain, FSMO holders and DC count**.
- **Now:**
  - When WinRM to the target works, the collector runs **on the target** (DCs and DNS/DHCP servers have their own modules).
  - When the target is DCOM-only, or the module is missing there, it runs **from this PC with RSAT, pointed at the target** (`-Server` / CIM session) with the supplied credentials.
  - Each section shows a **Collected Via** row (DHCP: a line).
  - A fallback adds a Collection Warning.
- New shared helper: `Invoke-IABBRoleQuery` (IABB.Core). `Invoke-IABBRoleCollectorTimed` now takes `-FunctionName -ComputerName -Credential -TimeoutSec -UseRemoting`.

### 2. One failure no longer stops the run (review H2)
- Each server's collection is protected: an unexpected error records the server as **Failed** (`New-IABBFailedResult`) and the run continues.
- Each DOCX is generated in its own `try/catch`. A failed DOCX is logged, shown in the HTML summary ("DOCX generation failed: ..."), and counted in the run summary.
- The DOCX files are now generated before the HTML summary, so the summary can report DOCX failures.

### 3. DOCX files can no longer be corrupted by control characters (review H3)
- New `ConvertTo-IABBCleanText` removes XML-illegal characters (0x00-0x08, 0x0B, 0x0C, 0x0E-0x1F, U+FFFE/FFFF, unpaired surrogates) before escaping. Used by both the DOCX and HTML writers (`ConvertTo-IABBXmlText`, `ConvertTo-IABBHtmlText`).

### 4. No more header-only tables; "Complete" never comes with empty tables (review H4)
- Processors, Storage Summary, Physical Disks, Volumes, Network Adapters, Hotfixes, Shares, Operating System and Role Services now show **"Not collected: the "<step>" collection step result was <result>"** when their step failed, timed out or returned no data. When data exists but the step was not fully OK, the table is shown with a "Partial data" note.
- Applications and Certificates: collected-but-empty now shows "Not collected: the ... query returned no data". The Executive Dashboard shows "Not collected" instead of 0.
- DHCP with no scopes: "No IPv4 DHCP scopes are configured on this server."
- **Zero-row sanity rule:** if Processors, Physical disks, Volumes, Network adapters, Services, Applications or Certificates return no rows, the step result becomes **No data**. That counts as failed, so the server is Partial with a warning.
- `Tbl()`/`TblFill()`: rows that don't fit the column grid are no longer dropped silently. A highlighted "Table data could not be laid out (n values for m columns)" row is written instead.

### 5. IIS (review M1)
- appcmd fallback: sites with **more than one binding** were dropped completely. The regex now captures all bindings.
- Binding host name is now parsed from `bindingInformation` (`ip:port:host`). It was always blank.

### 6. Run log (review M5)
- Everything in the log pane during a run is also written to `<run folder>\IABB_Run.log`. The log starts with a header: version, operator, credentials account, DCOM setting, time limits, server list. The run summary now includes DOCX created/failed counts.

### 7. Packaging and documentation (review L1, L2, L3, L7)
- Release notes file was named `v__VER__-ReleaseNotes.md`. It is now `v0.9.9g-ReleaseNotes.md`, plus this file.
- Added `Docs/Architecture.md`, `Docs/Roadmap.md` and `Assets/`.
- `Samples/` now use generic `contoso.local` names (they contained real client server names).
- README rewritten: requirements (RSAT, WinRM, admin rights, ports), `Unblock-File`, how to run, output, status meanings, troubleshooting.
