# v0.9.9g

## Fixed / added
1. ConvertTo-IABBReadableMode handles WindowsYYYY[R2][Interim](Forest|Domain), Windows2000MixedDomain, WinThreshold and numeric modes (0-7, 10).
2. Page File and Environment Variables sections use LocalAccountsNote ("Not collected: ...") when the step failed.
3. SQL collector: TcpDynamicPorts = 0 is shown as "Dynamic".
4. New role "Remote Desktop Session Host":
   - RDS-RD-Server Windows feature installed, or
   - root\cimv2\TerminalServices Win32_TerminalServiceSetting.TerminalServerMode = 1 (works over DCOM; queried with the CIM time limit).
   - Role Services lists RDS services that are present.

## Unchanged
- All v0.9.9f behaviour.
