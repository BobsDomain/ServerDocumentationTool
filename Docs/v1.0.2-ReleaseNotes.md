# v1.0.2 Release Notes

Built on v1.0.1. Fix release only.

## Fixed
- **The engine still failed to load in v1.0.1:** "Cannot process argument because the value of argument 'host' is null."
  - Cause: a runspace pool created with an engine session state (InitialSessionState) must be given a PowerShell host. v1.0.0 passed none. v1.0.1 switched to the `CreateRunspacePool(InitialSessionState)` overload, which also creates the pool without a host.
  - Fix: the app now has its own minimal, non-interactive PowerShell host (`AppPSHost`) and passes it to the pool. Engine output and progress are unaffected; progress still reaches the app through the Information stream.
- **Self-test log** (`--selftest`) now records the Windows version, process bitness, CLR version and the System.Management.Automation version and path. A failure on one machine can then be compared with the build runner.

## Unchanged
- Everything else from v1.0.1: the Server Documentation Tool name, report content, update button.

## Validation
- Static checks only here. GitHub Actions compiles the code and runs the app self-test (the app's own engine host collecting the build machine) before any release is published.
- Install test: from your installed v1.0.0 or v1.0.1, use **Check for Updates** (it works even though their engine fails to load). Confirm the app restarts as v1.0.2 and the log shows "Engine loaded".
