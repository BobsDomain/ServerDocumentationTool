# v1.0.3 Release Notes

Built on v1.0.2 (field-tested 2026-11-17: 153 servers in 34.5 minutes). Repository move only; collection and report content are unchanged.

## Changed
- **New repository location:** `https://github.com/bobsdomain/ServerDocumentationTool` (was `CPSDomain/ServerDocumentationTool`).
  - The update button, the updater's "download manually" link, the default `UpdateRepository` setting, the README and the file properties (Company/Copyright: bobsdomain) all use the new location.
  - **Installed copies are redirected safely.** Updating keeps each installation's own `Engine\Config\appsettings.json`, so older installs still say `CPSDomain/ServerDocumentationTool`. The app now reads that retired value as the new location (`UpdateService.ResolveRepository`). Updates never come from the old address, even if someone later re-creates a repository there.

## How to install
- **PCs with internet:** v1.0.2 already follows GitHub's redirect for moved repositories, so **Check for Updates** in v1.0.2 should find v1.0.3. From v1.0.3 on, the app uses the new address directly.
- **Servers without internet:** download the ZIP from Releases on a PC with internet, copy it to the server, unblock it and extract it over the old folder. Keep your `Engine\Config\appsettings.json` if you changed settings.

## Unchanged
- Everything from v1.0.2: app, engine, report content, self-test, update flow.

## Validation
- Static checks only here. GitHub Actions compiles the code and runs the smoke test and the app self-test (real local collection) before a release is published.
