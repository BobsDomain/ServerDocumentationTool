# v1.0.0 Release Notes: the Windows app

First release as a Windows application (`InfrastructureAsBuiltBuilder.exe`). It is built on the PowerShell engine v0.9.9i (locked baseline, field-tested on 153 servers on 2026-11-17) and compiled by GitHub Actions.

## New
- **Windows app** (C#, .NET Framework 4.8, WinForms). The PowerShell engine runs inside the app in a Windows PowerShell 5.1 runspace pool; no PowerShell console. It has the same features as the PowerShell version (client name, output path, alternate credentials, DCOM fallback, target list with manual entry / file import / local server / domain discovery / remove / clear, Test Reachability, Start Assessment, Open Output Folder). New in the app:
  - **Cancel**: stops running servers immediately and skips queued ones. Finished servers keep their JSON and DOCX; the HTML summary lists cancelled servers.
  - **Parallel collection**: **Servers at once** (1-16, default 4; `ParallelServers`). In the v0.9.9i field test the run took about 2 h 8 min one at a time, so several at once should cut that substantially.
  - **Hard time limit per server** (`ServerTimeLimitMinutes`, default 30). A server that runs longer is stopped without holding up the others and reported as Failed ("Time limit exceeded").
  - Row colours (running / complete / partial / failed / cancelled), **Browse...** for the output path, **Change...** to re-enter credentials, resizable window.
- **Update button.**
  - Checks the latest GitHub Release on start-up and on **Check for Updates**.
  - Downloads the ZIP and verifies its SHA256.
  - `IABB.Updater.exe` replaces the files after the app closes and restarts it. Your `Engine\Config\appsettings.json` is kept.
  - Uses the system proxy; failures are shown with the manual download link.
- **GitHub Actions build** (`.github/workflows/build.yml`) on every push:
  - parses every PowerShell file with Windows PowerShell 5.1;
  - runs PSScriptAnalyzer (report only);
  - runs an engine smoke test that includes a **real local collection** on the Windows build machine and validates the JSON, DOCX and HTML;
  - compiles the app and updater, and packages the ZIP plus SHA256.
  
  A `v*` tag publishes the GitHub Release.

## Fixed (engine)
- **The local server is now recognised by its full name.** Domain discovery lists servers as `SERVER.domain`, so the PC running the tool was treated as remote. WinRM to itself was refused, DCOM was used, and the server came out Partial (seen on the DC running the v0.9.9i field test). `Test-IABBIsLocal` now also matches `COMPUTERNAME.<DNS domain>` and the machine's DNS host name.
- `Test-IABBIsLocal` keeps recognising `.` (found by the first GitHub Actions smoke test: trailing-dot trimming had turned `.` into an empty name).
- **The local server is always collected as the signed-in user.** Windows does not accept alternate credentials for local connections; a warning notes when credentials were supplied.
- **One reusable PowerShell remoting session per server.** All WinRM steps (local accounts, applications, certificates, IIS, SQL, AD DS/DNS/DHCP on the target) share it. In the v0.9.9i test, two hosts spent about 84 s connecting for every step. If the session cannot be opened, each step connects on its own as before.

## Engine changes for the app
- New module `IABB.AppHost.psm1`: `Invoke-IABBAppServer`, `Invoke-IABBAppFailedServer`, `Complete-IABBAppServer`, `New-IABBAppSummary`. Progress is reported on the Information stream.
- Core: `Get-IABBLocalNames`, `Register-IABBSession`, `Get-IABBSession`, `Unregister-IABBSession`.
- New settings: `ParallelServers`, `ServerTimeLimitMinutes`, `UpdateRepository`, `CheckForUpdatesOnStart`. The PowerShell launcher ignores them.
- Version strings: 1.0.0 (DOCX "Generated By" / "Document Version", HTML, JSON SchemaVersion).

## Unchanged (regression guard)
- All report content and rules from v0.9.9i:
  - certificate and application listing;
  - Print Spooler note, role notes, File/Print/DFS roles, nested Hyper-V, Azure;
  - "Not collected" instead of empty tables, zero-row rule, mismatch row, XML-safe text;
  - AD DS/DNS/DHCP from the target, IIS bindings.
- Exported `New-IABBHtmlSummary`, `New-IABBOpenXmlDocx`; fixed column-grid tables; WSMan -> DCOM fallback; per-step try/catch; Collection Status banner; Hyper-V host = physical.
- Removed on purpose and still removed: Scheduled Tasks, AD DS DC/FSMO tables, DNS zone table.
- The PowerShell launcher `Engine\Start-InfrastructureAsBuiltBuilder.ps1` still works as a fallback.

## Known limitations
- Not code-signed: SmartScreen on first run; some EDR products may need an allow-list entry.
- The per-step limit (`SectionTimeoutSec`) can still overrun while a stuck step is being stopped. The per-server hard limit stops the server regardless.
- Requires administrator rights (UAC prompt).

## Validation
- Written and statically checked by Claude. The C# was syntax-checked with a C# parser; the PowerShell was checked for brace balance, exports and file sizes against v0.9.9i.
- **First GitHub Actions run (2026-11-17):**
  - syntax check passed;
  - smoke test: real local collection Complete in 107 s, collected locally, DOCX/JSON/HTML valid, 14 progress messages;
  - one failure (`.` not recognised as local), now fixed.

  Build and package run after the smoke test passes.
